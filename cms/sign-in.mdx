The Hot by Science CMS is the admin dashboard for managing patients and their lab work. Every CMS page sits behind sign-in. If you open a CMS page while signed out, the CMS redirects you to the sign-in page.

## Prerequisites

- An admin account with an email address and password.

## Sign in

<Steps>
  <Step title="Open the sign-in page">
    Go to the CMS. If you are not signed in, the **Sign In** page opens.
  </Step>
  <Step title="Enter your credentials">
    Enter your **Email** and **Password**. Both fields are required, and the email must be a valid email address.
  </Step>
  <Step title="Click Sign In">
    The CMS signs you in and opens the [Clinical & Lab](/cms/lab-requisitions) page.
  </Step>
</Steps>

If the email or password is wrong, the CMS shows "Your password is incorrect or this account doesn't exist." below the password field. The message disappears as soon as you edit the password.

## Reset your password

Use password recovery if you forget your admin password. The CMS emails you a six-digit code that you use to set a new password.

<Steps>
  <Step title="Open password recovery">
    On the **Sign In** page, click **Forgot password?**.
  </Step>
  <Step title="Enter your email">
    Enter the email address for your admin account and click **Continue**. If an eligible admin account uses this email, the CMS sends a recovery code to it.
  </Step>
  <Step title="Enter the code">
    Type or paste the six-digit code from the email. The CMS verifies the code as soon as you enter all six digits.

    If the code does not arrive, wait for the 60-second countdown to finish, then click **Resend**. Click **Change email** to go back and use a different address.
  </Step>
  <Step title="Set a new password">
    Enter your new password, confirm it, and click **Continue**. When the CMS shows **Password changed!**, return to the **Sign In** page and sign in with the new password.
  </Step>
</Steps>

Your new password must have:

- 8-20 characters
- At least 1 letter (A-Z)
- At least 1 number (0-9)
- At least 1 special character (`!@#$%^&*`)

<Note>
  If the code is incorrect or expired, the CMS shows an error under the code fields. Click **Resend** to get a new code.
</Note>

## Log out

Open the account menu in the top-right corner of the CMS, click **Log out**, and click **Yes** to confirm. The CMS ends your session and returns you to the **Sign In** page.
