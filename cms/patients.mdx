The **Patients** page lists every patient account. Use it to find a patient and check where their care plan stands.

## Prerequisites

- You are [signed in to the CMS](/cms/sign-in) as an admin.

## Open the patient list

In the sidebar, under **Operations**, click **Patients**.

The patient table shows these columns:

| Column | Description |
| --- | --- |
| **Full name** | The patient's name. A dot next to the name shows whether the account is active or inactive. |
| **Phone** | The patient's phone number. |
| **Email** | The patient's email address. |
| **Care Plan Status** | Where the patient's current care plan is in the lab and care workflow. |
| **Next Assessment** | The date of the next reassessment. Patients are reassessed every 90 days from the start of their care plan. |
| **Actions** | Row actions for the patient. |

Empty values show as `---`. The table is paginated.

## Search for a patient

Type in the **Search by name, email or phone number** box. The table updates as you type and returns to the first page. If no patient matches, the table is empty.

## Filter patients

Use the filters next to the search box to narrow the list. Changing a filter returns the table to the first page.

- **Care Plan Status**: Check one or more statuses to show only patients whose care plan has those statuses. Check **All** to show every status.
- **Account Status**: Select **Active** or **Inactive** to show only accounts with that status.

The **Care Plan Status** filter offers these statuses:

| Status | Meaning |
| --- | --- |
| **Intake Pending** | The patient has not finished intake. |
| **Awaiting Purchase** | The patient has not purchased their plan yet. |
| **Pending Requisition** | The care plan is waiting for a lab requisition to be sent. |
| **Sent to Lab** | The requisition was sent and the care plan is waiting for lab results. |
| **Processing** | Lab results are in and the care plan is in clinical review. |
| **Active** | The care plan is active. |
| **Canceled** | The care plan was canceled. |

## View a patient's details

Click a patient's row in the table to open their detail page. The page title shows the patient's full name, or their email address if no name is on file. To go back to the list, click **Patients** in the breadcrumb at the top of the page.

If the patient no longer exists, the page shows **Patient not found.**

The detail page has four tabs.

### Account

The **Account** tab shows the patient's profile. Empty values show as `---`.

| Field | Description |
| --- | --- |
| **First Name** | The patient's first name. |
| **Last Name** | The patient's last name. |
| **Sex** | The patient's sex. |
| **Date of Birth** | The patient's date of birth and current age, for example `March 8, 1985 (41 Years Old)`. |
| **Account Status** | Whether the account is **Active** or **Inactive**. A dot shows the status. |
| **Phone number** | The patient's phone number. |
| **Email Address** | The patient's email address. |
| **Address line 1** | The patient's address. |
| **Address line 2** | The second line of the patient's address. |

### Care Plans

The **Care Plans** tab lists the patient's current care plan. The care plan in progress is highlighted. If the patient has no care plan, the tab shows **No care plan yet.**

| Column | Description |
| --- | --- |
| **Care Plan ID** | The care plan's identifier. |
| **Active Date** | The date the care plan started. |
| **Cycle** | The reassessment cycle, which is 90 days. |
| **Next Assessment** | The date of the next reassessment. |
| **Status** | The care plan's status. See the [care plan statuses](#filter-patients) above. |

Click a care plan's row to open it on the [Clinical & Lab](/cms/lab-requisitions) page.

### Subscription

The **Subscription** tab will list the patient's subscriptions with their description, active date, expire date, and status. Subscriptions aren't recorded yet, so the tab shows **No subscriptions yet.**

### Consent

The **Consent** tab will list the consents the patient accepted, with the acceptance date and time, IP address, device information, and document version. Consents aren't recorded yet, so the tab shows **No consents yet.**

To manage a patient's lab work, use the [Clinical & Lab](/cms/lab-requisitions) page.
